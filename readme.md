This is a personal repository for storing notes worth sharing. Currently, it contains notes on:

- **Abstract Algebra**: Group theory, ring theory, factorization in integral domains, field theory, Galois theory, and the proof of the Abel-Ruffini theorem.
- **Number Theory**: Modular arithmetic, iterations, and applications of Lifting The Exponent Lemma (LTE).
